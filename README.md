# Paramount Marketing Landscape

An interactive map of where Paramount's marketing work happens and who makes it —
10 divisions, 39 projects, ~50 vendors, and decision-makers ranked by opportunity score.
Four views: Orbits, Flow / chain, Decision-maker board, and Overlap / shared vendors.

## Publish it (GitHub Pages)
1. Create a new **public** GitHub repo.
2. Upload **index.html** (this file) to the repo.
3. Repo **Settings → Pages** → Source: "Deploy from a branch" → branch `main`, folder `/ (root)` → Save.
4. After ~1 minute your link is `https://<username>.github.io/<repo>/`.

Single self-contained file — no build step, no dependencies.
