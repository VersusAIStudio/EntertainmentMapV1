# The Paramount Universe

An interactive business-development landscape map for Versus — Paramount at the
center, with all 10 networks, 21 decision-makers, and 34 projects rendered as
one navigable galaxy.

**Live site:** https://versusaistudio.github.io/ParamountUniverse/

## What it shows

- **Networks** (inner ring) — sized by how much work they hold, each with a live project count.
- **Decision-makers** — the people who hand out the work, grouped under their network.
- **Projects** — color-coded by opportunity:
  - 🔴 **Competitor-held** — an agency we'd beat currently has it
  - 🔵 **Big agency** — an incumbent that could hire Versus
  - 🟣 **Versus** — work we already do
  - ⚪️ **Up for grabs** — no agency attached yet (whitespace)

## How to use it

- Use the **tabs** across the top to fly into any single network.
- **Click any bead** — network, person, or project — for its full record in the
  side panel (status, who hands it out, incumbent agency, and how to approach).
- Scroll to zoom, drag to pan, and use the ◐ button to toggle light/dark.

## Tech

A single self-contained `index.html` — SVG + vanilla JavaScript, no build step
and no external dependencies. Hosted on GitHub Pages.
